# CloudMaker

Сервис управления виртуальными машинами на базе KVM/QEMU и libvirt с REST API на FastAPI и встроенным веб-интерфейсом.

## Возможности

* REST API: создание, запуск, остановка и удаление виртуальных машин (`/api/vms`).
* Инициализация: автоматическая генерация NoCloud ISO (cloud-init) для настройки учетных записей, паролей и SSH-ключей.
* Сетевое взаимодействие: создание и управление виртуальными NAT-сетями с DHCP (`/api/networks`).
* Контейнеризация: изоляция сервиса в Docker с управлением хостовым гипервизором через сокет libvirt-sock.
* Реестр образов: учет доступных cloud-образов ОС (`/api/images`).
* Квотирование ресурсов: превентивный контроль суммарного потребления vCPU и памяти.
* Мониторинг: экспорт метрик состояния ВМ и использования ресурсов для Prometheus (`/metrics`).
* Web UI: панель управления в браузере.

## Системные требования

Для работы требуются KVM и Docker (Ubuntu 24.04 LTS):
```bash
sudo apt update && sudo apt install -y qemu-kvm libvirt-daemon-system docker.io docker-compose-v2
sudo systemctl enable --now libvirtd docker
```

## Быстрый запуск

Запуск сервиса: `./run.sh`

Панель управления: http://localhost:8000/

## Тестирование и очистка

Интеграционные тесты: `./test.sh`

Очистка тестовых сущностей: `./cleanup.sh`
